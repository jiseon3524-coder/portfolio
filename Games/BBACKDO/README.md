# BBACKDO

아이템을 수집하고 제한된 가방 안에 배치하여 캐릭터를 강화하는  
**2D 탑다운 슈팅 액션 게임**입니다.

플레이어는 괴도가 되어 방을 탐험하고 몬스터를 처치합니다.  
획득한 아이템은 도감에 등록되며, 가방에 배치한 아이템만 실제 능력치에 적용됩니다.

## 게임 다운로드

[BBACKDO Windows 빌드 다운로드](https://github.com/jiseon3524-coder/portfolio/releases/tag/bbackdo-v1.0.0)

### 실행 방법

1. Release에서 `BBACKDO_Windows_v1.0.0.zip`을 다운로드합니다.
2. ZIP 파일의 압축을 완전히 해제합니다.
3. 압축을 해제한 폴더에서 `BBACKDO.exe`를 실행합니다.

> `BBACKDO.exe`, `BBACKDO_Data`, `UnityPlayer.dll` 등 빌드 파일이 같은 폴더에 있어야 합니다.  
> EXE 파일만 따로 이동하면 게임이 실행되지 않습니다.

## 조작 방법

| 키 | 기능 |
|---|---|
| `W`, `A`, `S`, `D` | 플레이어 이동 |
| `Space` | 공격 / 문 상호작용 |
| `E` | 도감 및 가방 열기 |
| `Tab` | 게임 방법 확인 |
| `ESC` | 일시정지 |

도감과 가방은 현재 방의 몬스터를 모두 처치한 뒤 열 수 있습니다.

```text
방 입장

→ 플레이어 능력치 적용
→ 문을 통해 다음 방 이동
→ 보스 전투
