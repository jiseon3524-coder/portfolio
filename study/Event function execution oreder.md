1. Unity가 자동으로 호출해주는 event function(start, awake,update등)을 사용하기 위해선 각 스크립트들은 Monobehavior을 상속받아야 한다.  
2. 게임이 실행되면 awake -> start -> update순서대로 실행된다.
3. awake는 게임이 시작 될 때 제일 먼저 호출된다. 예를 들어 오브젝트의 컴포넌트를 가져와야 하기 때문에 제일 먼저 실행되어야 한다. 전체적으로는 오브젝트 초기화를 위해 제일 먼저 실행된다.
4. start는 각 오브젝트가 준비가 되고 다른 오브젝트를 참조해야 할 때 실행된다. 만약 awake보다 start가 먼저 호출된다면, 오브젝트의 컴포넌트를 찾을 수 없는 NullRefernce오류가 생길 수 다.
5. Update는 본격적으로 게임이 시작되면서 매 프레임마다 호출되는 함수이다. 주로 플레이어 이동, 방향설정, 애니메이션 등이 여기에 속한다.
6. 그리고 Update는 화면에 한 프레임이 그려지기전에 호출되는 함수이다. 이게 없으면 즉각적인 피드백이 어려울 것 같다.
7. FixedUpdate는 보통 물리현상을 다룬다. 컴퓨터마다 다른 프레임으로 게임이 돌아가면 안되기 때문이다.
8. LateUpdate는 한 프레임에서 Update보다 늦게 호출되는 함수이다. 이 함수는 플레이어를 따라다녀야 하는 카메라가 있을 때, 카메라가 먼저 이동하는 현상을 방지하기 위해 필요할때가 있다.
