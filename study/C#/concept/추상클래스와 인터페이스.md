< 추상클래스 >
1. 보통 자식 클래스들의 공통부분을 모아 추상 클래스로 선언
2. 문법 : 확장자_반환값_abstract_class_클래스이름
3. abstract가 붙은 추상 메서드는 자식 클래스에서 필수적으로 구현해야함
4. 생성자를 사용할 수 없음
5. 필드, 메서드, 프로퍼티 등을 선언 가능
6. 다중 상속 불가

< 인터페이스 >  
1. 보통 자식 클래스들이 공통적으로 지켜야 할 틀을 인터페이스로 선언
2. 문법 : 확장자_반환값_class_I클래스이름
3. 인터페이스 내에 선언된 메서드는 자식 클래스들이 필수적으로 사용해야함
4. 생성자를 사용할 수 없음
5. 메서드만 선언 가능
6. 다중 상속 가능
